## 🤖 What Is thursday?

thursday is a free, open-source voice assistant that lives right on your computer. Instead of a single bot, it deploys a whole team of AI agents that work together in a real browser window while you simply talk. Imagine having a personal assistant who can browse the web, handle tasks, and respond to you conversationally—all without you touching a keyboard.

**No coding. No complicated setup. Just download, run, and start talking.**

## 🧠 How Does It Work?

When you speak, thursday connects to powerful AI models like OpenAI or Anthropic's Claude. It turns your voice into actions. The AI agents can:
- Open websites and navigate them
- Fill out forms and click buttons
- Search for information
- Control browser-based tools
- Answer questions naturally

All of this happens in a real browser window you can see. It's like watching a robot coworker do your tasks while you chat with it.

## 🧩 Advanced Features

### 🤝 Multiple Agents

thursday doesn't just use one AI—it manages a **team**. Here's how that helps:
- **One agent** reads your instructions

### 🔌 MCP Compatibility

thursday supports the **Model Context Protocol (MCP)**, which means it can connect to:
- File systems
- Databases
- Web APIs
- Custom tools

This makes thursday incredibly flexible for power users who want to automate almost anything.

### 🏠 Local-First Design

Your conversations and data are processed **on your computer**, not on someone else's server. This means:
- 🔒 More privacy
- ⚡ Faster responses
- 💾 Works even with slow internet

## ❓ Frequently Asked Questions

### ❔ Is thursday really free?

Yes! thursday is open-source, which means the code is free forever. You only pay for the AI API usage (if you use OpenAI or Anthropic directly).

### ❔ Do I need to know how to code?

Absolutely not. thursday was designed for everyday users. If you can talk, you can use thursday.

### ❔ Can I use it without an API key?

You can download and explore the interface, but to actually use the AI features, you'll need an API key from OpenAI or Anthropic.

### ❔ Will it work on my computer?

If you're running Windows 10 or newer with at least a stable internet connection, you should be good. thursday is lightweight and doesn't need a high-end graphics card.

### ❔ Can I change the voice?

Yes! thursday comes with multiple voice options. Just go to settings and pick the one you like best.
